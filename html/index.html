Dúvidas frequentes

Preciso criar uma conta?

Não. Basta abrir o painel e começar a cadastrar seus hábitos.

Onde meus hábitos ficam salvos?

Os dados ficam no navegador utilizado. Limpar os dados do site pode apagar seus registros. Não há sincronização entre dispositivos.

Posso usar pelo celular?

Sim. A interface se adapta a celulares, tablets e computadores.
