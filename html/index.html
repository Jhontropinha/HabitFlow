Dúvidas frequentes

Preciso criar uma conta?

Não. É possível navegar livremente pelo protótipo e explorar as telas.

Onde meus hábitos ficam salvos?

Esta versão de apresentação não salva hábitos. Os cartões, metas e indicadores são fictícios. O projeto original com JavaScript permanece preservado em outra versão do repositório.

Posso usar pelo celular?

Sim. O layout responsivo foi construído com CSS para celular, tablet e computador.
