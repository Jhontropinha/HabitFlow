# HabitFlow — Protótipo HTML e CSS

Protótipo navegável de uma aplicação para organizar hábitos e conhecer o conceito de **Modo Adaptativo**, com uma rotina Leve, Normal ou Intensa.

## Tecnologias

A versão desta branch usa **apenas HTML5 e CSS3**, sem JavaScript, frameworks, backend ou banco de dados.

## Páginas

- `html/index.html`: apresentação do projeto.
- `html/dashboard.html`: hábitos e indicadores de exemplo.
- `html/meu-dia.html`: alternância visual entre Leve, Normal e Intenso usando radio buttons e CSS.
- `html/calendario.html`: calendário ilustrativo de novembro de 2026.
- `html/metas.html`: metas e barras de progresso ilustrativas.

Abra `index.html` na raiz, ou `html/index.html`, no navegador. O Live Server do VS Code também funciona.

## Limitações declaradas

Esta é uma **demonstração visual**. Os dados dos hábitos e das metas são fictícios; os valores dos indicadores não mudam automaticamente. Selecionar os modos ou marcar caixas demonstra apenas a interface. **Não há cadastramento real, histórico persistido, exportação/importação JSON ou salvamento local.**

A versão anterior com lógica JavaScript permanece no histórico do Git e na branch `main` até que esta demonstração seja aprovada e integrada.
