# HabitFlow — Protótipo HTML e CSS

Protótipo acadêmico navegável para demonstrar uma interface de acompanhamento de hábitos com um diferencial: o **Modo Adaptativo**, que apresenta rotinas **Leve**, **Normal** e **Intensa**.

## Tecnologias e escopo

- **HTML5:** estrutura semântica, navegação, formulários visuais, `<details>`, botões de opção e barras `<progress>`.
- **CSS3:** layout responsivo, cartões, cores, estados selecionados e troca visual das rotinas.
- **Sem JavaScript, backend, banco de dados ou frameworks nesta versão.**

**Atenção:** este é um **protótipo visual**, não um aplicativo de hábitos funcional. Os dados são **exemplos fictícios**, as marcações não são salvas e as métricas não são recalculadas automaticamente.

## Como abrir

1. Baixe ou clone o repositório.
2. Abra `index.html` na raiz com o navegador ou use **Open with Live Server** no VS Code.
3. Siga os links para conhecer as cinco páginas.

## Páginas

| Página | Conteúdo demonstrado |
| --- | --- |
| `html/index.html` | Apresentação do projeto, recursos e dúvidas |
| `html/dashboard.html` | Cartões de hábitos e indicadores ilustrativos |
| `html/meu-dia.html` | Alternância visual entre Leve, Normal e Intenso usando radio buttons e CSS |
| `html/calendario.html` | Calendário de novembro de 2026 com estados fictícios e um histórico de exemplo no dia 13 |
| `html/metas.html` | Metas ilustrativas e barras de progresso nativas |

## Teste rápido da apresentação

1. Confirme que todos os links do menu abrem suas páginas.
2. Em **Meu Dia**, selecione os modos Leve, Normal e Intenso e observe a mudança visual das listas.
3. Em **Calendário**, selecione o **dia 13** para navegar até o histórico ilustrativo.
4. Em **Metas**, verifique as barras de progresso demonstrativas.
5. Teste o layout em aproximadamente **390 px** de largura e no desktop.

## Limites do protótipo

- Não cadastra, exclui nem salva hábitos.
- Não importa nem exporta backups.
- Não atualiza automaticamente datas, progresso ou sequências.
- As caixas de seleção do dashboard apenas ilustram estados visuais.
- A troca de modos funciona visualmente com HTML e CSS, mas não cria registros persistentes.
